# 文字与视频设置

退出游戏后编辑 fabric_loading/config.json，保存为 UTF-8。JSON 不支持注释，最后一个字段后面不能多一个逗号。建议先备份文件；配置写错时程序会记录错误并使用默认值。

## 换视频和音量

默认读取 video/loading.mp4，原视频分辨率不限，播放时按 width、height 缩放：

~~~json
{
  "video": "video/loading.mp4",
  "width": 640,
  "height": 360,
  "fps": 30,
  "queueFrames": 3,
  "audio": true,
  "audioFile": "",
  "volume": 0.8,
  "fadeOutMs": 450
}
~~~

这是需要修改的字段示例，实际修改时保留完整模板中的其他字段。

audioFile 为空表示播放视频音轨；填写 audio/music.m4a 可以指定另外的音频。audio 为 false 则关闭声音。volume 范围 0–1。fadeOutMs 是加载完成后的渐隐毫秒数。

默认 640×360 适合先验证功能。想更清晰可改成 960×540，代价是更多解码、像素转换和窗口缩放工作。width、height 会限制为 320×180 至 1920×1080，并取偶数；fps 限制在 30–60；queueFrames 限制在 2–6。提高参数不代表实际帧率一定提高。

## 自动标题和固定标题

保持 "title": ""，并让 ui.title.text 使用 "${packName}"，就会显示自动读取的整合包名称。

自动读取顺序是 modrinth.index.json.name、manifest.json.name、启动参数 --version、游戏目录末级文件夹名。文件夹叫“我的整合包”，但启动器传来“测试版”，界面会优先显示“测试版”。必须完全使用某个名字时，可把 title 改成该名字。

不要把完整磁盘路径填进 title。读取磁盘根目录时没有末级文件夹名称，程序会使用 Minecraft 作为备用标题。

## 字体、颜色和位置

把有使用许可的字体放进 fabric_loading/fonts/，例如 fonts/pack.ttf。全局 font 设置为这个相对路径，所有文字默认使用它。单独一段文字也可以设置自己的 font。

修改 ui.title 的示例：

~~~json
"title": {
  "text": "${packName}",
  "font": "fonts/pack.ttf",
  "size": 38,
  "weight": "bold",
  "color": "#FFF4DC",
  "opacity": 1,
  "anchor": "top-left",
  "x": "50",
  "y": "440",
  "enabled": true
}
~~~

画布按 1280×720 排版，再随窗口缩放。x 和 y 可以是数字字符串，也可以是百分比，例如 "50%"。文字位置表示文字区域起点，实际字形会按字体基线排列。

size 是字号，范围 8–180；weight 使用 bold 或 normal。color 使用 #RRGGBB 或 #RRGGBBAA，最后两位是透明度。opacity 范围 0–1。enabled 设为 false 可以隐藏该项。

anchor 可使用 top-left、top-right、bottom-left、bottom-right、center。例如居中标题设置 anchor 为 center，x 为 "50%"，y 为 "50%"。长标题可能被截断，可减小字号或调整位置。

ui 中可修改 title、subtitle、status、tasks、mods、percent。tasks 显示实际回调条目，内容由程序生成，修改 text 不会覆盖任务名；字体和位置仍可修改。maxTasks 控制最多显示多少条，taskSpacing 控制行距。

可用文字变量：

| 变量 | 内容 |
| --- | --- |
| ${packName} | 自动读取或手动指定的整合包名 |
| ${subtitle} | 全局 subtitle |
| ${stage} | 当前加载说明 |
| ${overallPercent} | 总进度百分比 |
| ${modCount} | 已发现的模组数量 |
| ${sourceLabel} | 进度数据来源 |

主进度请使用 overallPercent。它是同一条总进度，任务切换不会归零。

## 进度条和底部遮罩

ui.progress 中 x、y、width、height 控制位置和尺寸，color 控制已完成部分颜色，background 控制轨道颜色，radius 控制圆角，opacity 控制透明度。

ui.dimBackground 开启底部暗色渐变，shadeOpacity 控制渐变的最大透明度。这个渐变只覆盖视频，不应让桌面透过背景。游戏内是否存在透明、闪烁或窗口交接问题，需要实际启动验证。

本版尚未接入 Forge 作者工具。手动复制 Jar 和 fabric_loading 文件夹即可配置开发版，切勿用 Forge 工具覆盖 Fabric 文件。
